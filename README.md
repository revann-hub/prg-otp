# prg-otp
This code is a simple encryption tool that generates random numbers using a seed value provided by the user and encrypts text through XOR operations. The convert_to_binary function converts input numbers to 8-bit binary format, while xor_operation performs XOR operations on two numbers. The convert_to_decimal function converts binary numbers back to decimal format. The encrypt_message function uses the seed value to generate random key numbers and encrypts each character by XORing it with these keys. The decrypt_message function uses the same seed value to generate identical keys and restores the encrypted text to its original form. The same seed value must be used for both encryption and decryption.
